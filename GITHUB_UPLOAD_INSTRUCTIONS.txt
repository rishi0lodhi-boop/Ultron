🆘 NEED HELP?

Common issues:

❌ "Build Failed"
   → Check Actions tab for error
   → Usually: files not uploaded properly
   → Re-upload carefully

❌ "No APK Download"
   → Build still running (5-10 min)
   → Must show ✅ first
   → Scroll down for Artifacts

❌ "APK Won't Install"
   → Enable "Unknown sources" in phone
   → Or use ADB from computer
